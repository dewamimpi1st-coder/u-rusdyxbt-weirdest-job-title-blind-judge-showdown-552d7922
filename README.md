## Entry

> Senior Apologizer for Elevators That Close Too Fast

51 characters, one line. The title sounds like a real senior corporate role — "Senior Apologizer" — until the one hilariously specific twist lands: the job is apologizing on behalf of elevators that close too fast. Everyone has been caught by those doors, so the grievance is instantly relatable, and the twist is specific enough to be funny on first read rather than a generic oddity.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, standard library only, no network, deterministic) writes exactly the entry line above to `/output/entry.txt`, creating `/output` first if needed. It throws if the line is outside 1–60 characters, if it is not a single line, or if it is only white space, and reads the file back after writing, throwing if the content or its UTF-8 bytes do not match exactly.
